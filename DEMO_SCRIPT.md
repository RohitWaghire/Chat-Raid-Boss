# Demo script: Chat Raid Boss (target 2:00)

One take, one browser window, OBS open in a second window. Unmute the system audio before you start recording so the sound effects come through.

| Time | Screen | Action | VO |
|------|--------|--------|----|
| **0:00–0:10** | Landing page | Scroll the hero slowly, then click into the studio. | "What if your whole Twitch chat was one raid party, and the boss fought back?" |

## Notes

- **Twitch requirement:** the 0:30–1:00 segment must show the overlay working on real Twitch, with the Twitch chat panel visible next to it.
- **Backup:** if live chat is quiet, use demo mode (`/overlay?demo=1`) for the later segments. Keep at least 20 seconds of real Twitch chat in the cut.
- **Pacing:** if you run long, trim the landing (0:00–0:10) and the storyboard (1:52–2:00) first. Never cut the live chat segment.
